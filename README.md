# Módulo de Registro y Autenticación de Usuarios

**Programa:** Tecnólogo en Análisis y Desarrollo de Software (ADSO) - SENA.  
**Autora:** Kellin Dayana Vargas Quijano.

## Descripción del Proyecto
Aplicación web desarrollada en **React** que implementa el proceso de **registro de nuevos usuarios** y **autenticación (inicio de sesión)** con validación de credenciales. Si los datos ingresados no coinciden con ningún usuario registrado, el sistema muestra un **mensaje de error**; si la validación es correcta, muestra un **mensaje de éxito** y da acceso al panel del usuario.
